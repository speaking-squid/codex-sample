# codex-sample

This repository contains a simple Python-based Snake game that runs directly in the browser using [PyScript](https://pyscript.net/).

## Running the Game

1. Ensure you have an internet connection so that PyScript assets can be loaded.
2. Open `index.html` in a modern web browser.
3. Use the arrow keys to control the snake. The snake wraps around the edges and your score increases each time you eat the red food square.

No additional setup is required.
